# resona-site

Source of [resona.syalia.com](https://resona.syalia.com), the product site of Resona, a voice creation studio by Syalia.

It is one static page in English and Spanish, with no build step and no third-party requests: fonts, data and audio are served from this repo.

## Layout

| Path | What |
|---|---|
| `index.html` | The page. Every translatable node carries `data-en` and `data-es` (or `data-en-html` / `data-es-html`). |
| `css/site.css` | Styles. |
| `js/site.js` | Language switch and the Emotion CAD map. No dependencies. |
| `data/emotions.json` | Emotion catalog for the map, generated by `scripts/build_emotions.py`. |
| `audio/parlantia/` | Three short excerpts published by [Parlantia](https://parlantia.diaitu.com) as samples, copied unchanged. |
| `audio/emotions/` | Emotion CAD clips (see below). Not present yet. |
| `fonts/` | Recursive (Latin subset, `wght` 400–700 and `MONO` axes) and Inter 400/500, with their OFL licences. |
| `scripts/subset_fonts.sh` | Rebuilds `fonts/recursive-latin.woff2` from the official Recursive release. |
| `CNAME` | `resona.syalia.com` |
| `.github/workflows/pages.yml` | Deploys `main` to GitHub Pages. Skips until Pages is enabled with "GitHub Actions" as source. |

## Run it locally

```bash
python3 -m http.server 8000
```

Then open http://127.0.0.1:8000/. The page loads `data/emotions.json` with `fetch`, so opening the file directly from disk does not work.

The initial language comes from `navigator.language` (Spanish when it starts with `es`); the EN/ES toggle is saved in `localStorage` under `resona-lang`.

## Emotion catalog

The map computes the same parameters as `EmotionManager.calculate_parameters` in Resona (`src/emotions/manager.py`):

- temperature = 0.90 + Δtemp × m, clamped to [0.01, 1.99]
- repetition penalty = 1.05 + Δpenalty × m, at least 0
- top-p = 1.00 + Δtop_p × m, clamped to [0.01, 1.00]

where m is the intensity multiplier: 0.25 (minimal), 0.6 (subtle), 1 (normal), 1.4 (strong), 2.0 (extreme).

To regenerate `data/emotions.json` from a Resona checkout:

```bash
python3 scripts/build_emotions.py path/to/resona/resources/emotions.json
```

The script also lists the clips found under `audio/emotions/`, so run it again after adding clips.

## Emotion CAD clips

The map works without audio: until a clip exists, its slot says "Sample coming" and the play button stays disabled. The page expects these 18 files, generated by Resona with the factory voice `system_female`, saying the same sentence of about 5 s:

- English: "The letter arrived this morning."
- Spanish: "La carta llegó esta mañana."

Format: Opus, mono, 32 kbps (about 20 KB each). Names are `audio/emotions/<lang>/<emotion>-<intensity>.opus`:

```text
audio/emotions/en/calm-normal.opus        audio/emotions/es/calm-normal.opus
audio/emotions/en/happy-normal.opus       audio/emotions/es/happy-normal.opus
audio/emotions/en/sad-normal.opus         audio/emotions/es/sad-normal.opus
audio/emotions/en/angry-normal.opus       audio/emotions/es/angry-normal.opus
audio/emotions/en/whispering-normal.opus  audio/emotions/es/whispering-normal.opus
audio/emotions/en/ominous-normal.opus     audio/emotions/es/ominous-normal.opus
audio/emotions/en/angry-minimal.opus      audio/emotions/es/angry-minimal.opus
audio/emotions/en/angry-strong.opus       audio/emotions/es/angry-strong.opus
audio/emotions/en/angry-extreme.opus      audio/emotions/es/angry-extreme.opus
```

Then run `scripts/build_emotions.py` so the clips appear in `data/emotions.json`. Emotions with a clip get a dot on their chip. Clips load only when a visitor presses play.

## Preview status

Resona is in preview. Until its source is public with a licence, the page shows no link to the code and no install commands; the call to action is hello@syalia.com. When the source is published, add the GitHub link (hero button and footer), the install block in "Run it", and change the "Status" text in both languages.
